# College Event Management System

## 📌 About the Project

The College Event Management System is a web-based application designed to simplify the management of college events and student participation.

The system allows students to register for events and helps manage event information and participants efficiently.

## 🚀 Features

- Student registration
- Student management
- Event creation and management
- Event registration
- Participant management
- Event information
- Leaderboard
- Database management

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
